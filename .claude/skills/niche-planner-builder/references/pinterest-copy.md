# Pinterest-Ready Pin Copy

A separate, shorter copy deliverable from the Etsy listing — Pinterest is a discovery/search
platform with its own conventions, and pasting the Etsy description into a pin reads as bloated and
under-optimized. Produce 2-3 pins, each with its own title/description/hashtags angled at a
different buyer motivation (overview, a standout feature, gift-giving) rather than one pin repeating
the same copy as the others.

## Per-pin structure

- **Title** — under 100 characters, ideally 40-70 so it doesn't truncate in feed view. Front-load
  the primary keyword phrase, same discipline as the Etsy title but much shorter — this is a
  headline, not a feature list.
- **Description** — 150-300 characters. Pinterest allows up to ~500, but shorter reads better and
  still ranks well; the field is for search/discovery keywords woven into a natural sentence or two,
  not a keyword pile. Include a soft call-to-action ("Grab it on Etsy," "Instant download") since
  that's the actual next step for a buyer who clicks through.
- **Hashtags** — 3-5 relevant tags appended to the description. More than that reads as spammy to
  Pinterest's own ranking and doesn't help — this is different from Etsy's exactly-13-tags rule,
  don't carry that number over.
- **Suggested boards** — 2-4 board name suggestions (e.g. "Baby Shower Ideas," "Digital Planners &
  Printables," "New Mom Gifts") so the seller knows where to actually pin it, not just what to say.
- **Recommended pin image** — name the specific image from the Etsy asset set that fits this pin's
  angle (the hero for an overview pin, the feature-icon slide for a features pin, the lifestyle
  photo for a gift-angle pin).

## The vertical-format gap

Pinterest's own ranking favors **2:3 vertical images (1000x1500px)** — this is a real, documented
platform preference, not a minor stylistic note. Every image this skill produces in Phase 3/3b is
4:3 landscape (matches Etsy's listing-image convention, where landscape/square work fine). Don't
silently reuse a 4:3 image as a Pinterest pin without flagging it: note in the delivered copy file
that the recommended image should be re-cropped or re-exported at 2:3 before pinning, since a
landscape image posted directly to Pinterest gets letterboxed and performs worse. Producing an
actual dedicated vertical pin graphic (reusing the same green-screen/composite techniques from
`marketing-imagery.md` and `feature-slides.md`, just at a 2:3 canvas instead of 4:3) is a good
next step if the user wants full Pinterest optimization, but isn't produced by default — the copy
deliverable stands on its own even before that image work happens, so don't block delivering the
copy on it.

## Where this fits in the workflow

Read this file at **Phase 5b**, right after the Etsy listing copy (Phase 5) — Pinterest copy reuses
the same feature list, palette names, and buyer framing already established for the Etsy listing,
so writing it right after keeps that context fresh rather than re-deriving it later.

## Output location

Save as `MDRN/<Niche>/Pinterest/Pinterest Pin Copy.txt`, sibling to the niche's `HTML/` and `Etsy/`
folders (see Phase 1's folder-structure rule in SKILL.md) — Pinterest copy is a distinct deliverable
from the Etsy listing text, not a section tacked onto the same file.
