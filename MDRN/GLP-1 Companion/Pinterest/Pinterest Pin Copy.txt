--------------------------------------------------------------------------------
VERTICAL-FORMAT NOTE — ACTION NEEDED BEFORE PINNING
--------------------------------------------------------------------------------

Pinterest ranks 2:3 vertical images (1000 x 1500 px) noticeably better than
landscape. Every image produced for this listing so far is 4:3 or wider, because
that is the Etsy listing convention — posting one straight to Pinterest gets it
letterboxed and it will underperform.

Before pinning, either:
  (a) re-crop the recommended image to 2:3 at 1000 x 1500, or
  (b) commission a dedicated 2:3 pin graphic using the same composite treatment
      as the Etsy hero (same house wordmark, same Hanken Grotesk headline, same
      amber accent word), just on a 1000 x 1500 canvas.

Option (b) is the better result and is not produced by default — say the word and
it can be built alongside the remaining Phase 3 imagery.

One more option worth knowing about: the 9:16 vertical video already produced for
this listing (`Etsy/video/glp1-companion-vertical.mp4`, 24s) can be uploaded as a
Pinterest Idea Pin as-is. Video pins are not subject to the 2:3 still-image
convention, and that file is already the right shape.
